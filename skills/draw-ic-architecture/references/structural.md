# 结构图、微架构与流程图

以下为方法建议，不是对任何商用芯片未公开结构的断言。案例索引见 source-atlas。

## 1. 系统层级

先列实体、包含关系、连接、方向、复制数和接口。总览回答模块在哪里、怎样通信；不要把完整微操作流水塞进总览。

- 用容器表示 package → die/chiplet → cluster → core → PE。最多同时展现三层，深层细节用同名实体关联的独立放大面板。
- 外存置芯片边界外，共享 SRAM/缓存置真实共享边界内。cache、scratchpad、寄存器文件不可混名。容量与带宽分别标，未知则省略。
- 真实拓扑优先：bus 主干+分支，mesh 邻接，crossbar 交换模块，ring 闭环，broadcast 源与 fan-out；不得为了排版改为全连接。
- 数据实线、控制虚线，颜色补充而非唯一编码。双向协议可用两条有标签单向边；不要暗示同周期双向满带宽。
- 一条边一种关系，连接到边缘或端口；避开模块和文字。线交叉不等于连接，连接需明确 junction。
- 重复单元用代表 PE 和 ×N，说明省略范围。逻辑图大小不代表硅面积；若用大小编码面积必须所有模块同一比例并注明。

## 2. 数字数据通路与微架构

按实际实现画输入→解码/拆分→运算→规约/累加→舍入/输出。算术节点使用功能名或明确标准符号。MUX 显示数据与选择端，寄存器用窄矩形表达边界。

- 有依据才标位宽、signedness、lane 数和 accumulator 精度；FP8×FP4→FP32 比“FP4 mode”精确。
- 寄存器边界标 S0/S1/S2，区分 latency 与 II。跨周期反馈必须经过真实寄存器/存储，不画无延迟组合环。
- valid 向前、ready 反向；解释 stall 是否冻结各级。只画数据通路时图注说明控制省略。
- CDC FIFO、同步器、时钟域边界按实际设计添加；跨时钟“同一拍”不可共用无解释时间轴。
- baseline/proposed 布局、尺度、端口顺序一致，只强调修改模块，不靠拥挤程度暗示性能优劣。

## 3. 阵列与数据复用

声明 M/N/K 与物理行列对应关系。A/B/psum 各用固定线型/颜色；长 token 序列放时间面板。区分空间广播、邻接转发和时间复用，不用粗箭头隐藏网络成本。

脉动图标注注入方向与 skew；广播图显示源 buffer 和 fan-out；规约树显示层次；点积 PE 区分 K 路乘法、规约与累加。“2×2 组内广播、组间脉动”要画清组边界与跨组寄存器。K=16 单拍是实现约束，不由图保证。

## 4. 时序与控制

cycle 横轴、stage/resource 纵轴，token 配色一致；区分 idle、依赖、访存、通信等待。重叠执行不能简单堆叠相加为总时间。FSM 节点=状态，边=条件/动作，明确 reset 初态、互斥分支和出口。“调度阶段”与“硬件流水级”不能混用。

## 5. 建模与 DSE 流程

输入（模型、workload、硬件规格、库）、处理（mapping、仿真、估计）、输出（时间、能量、面积）使用不同形状或填充。真实判断才用菱形，每个分支标条件。分开外层硬件搜索与内层 mapping 搜索，不能把一次差映射当成硬件极限。

展示 calibration/validation 与实测来源、非法设计过滤、约束判定与结果保存。循环线绕到框外，不穿文字。算法细节默认放图注，除非它是主论点。

## 6. 论文风格

白底、矩形、无阴影/渐变/3D。最终文字建议 8–10 pt、最小约 7 pt，线宽 0.6–1 pt；投稿模板优先。单栏约 3.35 in、双栏约 7 in 只是起始值。务必按最终栏宽检查。

计算淡蓝、存储淡绿、控制淡橙、互联浅灰，强调最多一色。留白 5–10%，同类等宽、端口对齐，网格 10–20 px。宁可换行/拆面板，不把文字缩到无法阅读。图例仅解释不自明符号。
